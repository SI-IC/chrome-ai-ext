# OpenAI Compatible LLM Assistant с навигацией по сайту

Расширение для браузера Chrome, которое позволяет подключать любую LLM через OpenAI-совместимый API и **управлять веб-страницами** - навигация, клики, ввод текста, скроллинг и другие действия.

## Возможности

### 🤖 Чат с контекстом страницы
- Анализирует содержимое текущей страницы (заголовки, ссылки, текст)
- Отвечает на вопросы о странице
- Выполняет действия на странице по команде

### 🎯 Действия, которые может выполнять LLM

1. **Навигация** - переход по URL
   ```
   [[NAVIGATE:https://example.com]]
   ```

2. **Клики** - клик по элементам (кнопки, ссылки, и т.д.)
   ```
   [[CLICK:Login]]
   [[CLICK:#submit-btn]]
   [[CLICK:.nav-item]]
   ```

3. **Ввод текста** - заполнение полей ввода
   ```
   [[TYPE:#email|user@example.com]]
   [[TYPE:[name=password]|mypassword]]
   ```

4. **Скроллинг** - прокрутка страницы
   ```
   [[SCROLL:down]]
   [[SCROLL:up]]
   [[SCROLL:top]]
   [[SCROLL:bottom]]
   ```

5. **Выбор в dropdown** - выбор опций в селектах
   ```
   [[SELECT:#country|USA]]
   ```

### 📋 Контекстное меню
- **Explain with LLM** - объяснить выделенный текст
- **Summarize with LLM** - кратко изложить выделенное
- **Translate with LLM** - перевести выделенное
- **Chat about this selection** - обсудить выделенное с учетом контекста страницы

### 🖥️ Side Panel
- Боковая панель для удобного чата во время просмотра страниц
- Быстрые действия (скролл, суммаризация)
- Информация о текущей странице

## Установка

1. Откройте Chrome и перейдите на `chrome://extensions/`
2. Включите **Developer mode** (переключатель в правом верхнем углу)
3. Нажмите **Load unpacked**
4. Выберите папку `llm-extension`

## Настройка

1. Кликните по иконке расширения
2. Перейдите на вкладку **Settings**
3. Заполните параметры:
   - **API Base URL** - например, `https://api.openai.com/v1` или `http://localhost:11434/v1` для Ollama
   - **API Key** - ваш API ключ
   - **Model Name** - название модели (например, `gpt-3.5-turbo`, `llama2`, `mistral`)
   - **Max Tokens** - максимум токенов в ответе
   - **Temperature** - креативность (0-2)
   - **System Prompt** - системная инструкция для LLM

## Как это работает

1. **Content Script** (`content.js`) - внедряется на каждую страницу, предоставляет доступ к DOM
2. **Background Script** (`background.js`) - обрабатывает запросы к LLM, парсит специальные команды `[[ACTION:...]]` и выполняет действия
3. **Side Panel** (`sidepanel.html/js`) - интерфейс для чата с контекстом страницы
4. **Popup** (`popup.html/js`) - настройки и простой чат

## Синтаксис команд для LLM

LLM отвечает в специальном формате, который расширение парсит и выполняет:

- `[[NAVIGATE:url]]` - перейти по URL
- `[[CLICK:selector]]` - кликнуть элемент
- `[[TYPE:selector|text]]` - ввести текст
- `[[SCROLL:direction]]` - скроллить
- `[[SELECT:selector|value]]` - выбрать опцию

Системный промпт автоматически добавляет эту информацию в запрос к LLM вместе с контекстом страницы.

## Безопасность

⚠️ **Внимание**: Расширение имеет доступ ко всем веб-страницам. Используйте доверенные LLM и не вводите чувствительные данные в чат.
